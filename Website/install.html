Install Nova Player to launch and play Nova games.

Download Nova Player

Nova Player is required to launch games from the Nova website.

Download for Windows

How to Install

  1. Click Download for Windows.
  2. Open NovaPlayerSetup.exe.
  3. Follow the Nova Player installer.
  4. Finish installation.
  5. Come back here and click I Already Installed It.

Launch Test

This currently launches the Nova Baseplate demo using:

nova-player://play?placeId=1
